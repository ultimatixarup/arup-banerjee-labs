The browser version of the free, open-source agent-ops-check CLI. Same rules, same scanners, same score. Pick a folder, a .zip or files. Everything runs in this tab: the page has no server, makes no network requests (its Content-Security-Policy blocks them), and sends no analytics about what you scan.

Heuristic checker, not a security audit. Regex and static checks. It can miss real problems and flag harmless code. A clean score is not a guarantee. Standards are shown as “maps to”; this is not a compliance assessment.

    What it checks

    1. Personal-to-work data crossover: agents that read personal sources (mail, files, chats) and write to work channels; shared credentials; secrets (masked) and PII.
    2. Irreversible actions: send, pay, delete, deploy, submit and browser writes, with a gate map (approval, dry-run, rate limit, allowlist).
    3. Governance and cost: AI inventory, token and step caps, loops, logging, model pinning.
    4. Labs tools: Agent Health Checker, Cloud Bill Smell Detector, Observability Gap Finder.
    5. ADSF prompt-injection scan over every document: hidden instructions, invisible Unicode, base64 payloads, exfiltration links.

      Includes 8 rules derived from Microsoft’s LLMail-Inject dataset (MIT License). On 500 held-out attacks the scan flags 66.8% at any severity and 44.6% at medium or higher, with 0/203 false positives on the dataset’s benign emails; about a third of attacks are still missed. Benchmark details.

    6. STE style checks inspired by ASD-STE100 writing rules (not a certified ASD-STE100 checker), plus an information-loss compare.
    7. Standards map for 10 frameworks (“maps to”, not compliance) and generated eval sets (generated, not run).

    Each “Maps to” list comes from the tool’s offline standards data (data/standards/): ✅ = the tool checks for evidence of it, 🟡 = partly. It shows what the checks relate to, not compliance. Standards and datasets are named for reference only; this project is not affiliated with or endorsed by Microsoft, OWASP, NIST, ISO, MITRE, CSA, Anthropic or the EU.

    Prefer the command line? npx github:ultimatixarup/agent-ops-check ./my-agents. The CLI also offers an optional LLM review with your own key; the browser version has no LLM option, so nothing ever leaves the tab.
