FAQ

Does my config get uploaded?

No. Analysis runs in your browser. Nothing in the paste is sent to a backend for scoring.

What formats work?

LangGraph-style JSON/YAML, agent.yaml, prompt + tools lists, and similar free-form agent config text.

Is this a security audit?

No. It’s a free heuristic scorecard — not a penetration test or formal audit. Self-check on what you paste only.

Will it false-flag secrets?

Possibly. Redact before pasting if unsure. Analysis still stays local.

Do I need an account?

No. Open, paste, score. No waitlist or email is required.

Is it really free?

Yes. This tool is free forever. No account or email is required.
