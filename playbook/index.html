Who it’s for

Anyone who can communicate. That includes:

  • people returning to work, including homemakers;
  • career changers;
  • professionals outside software;
  • developers, including 30-year Java veterans.

You need an AI chat assistant you already use (many have free tiers), or a friend for the paper version. Nothing to install for Module 1. No sign-up on this site.

Free, on this site

No signup on this site, no account here, nothing to buy. The Hands-Off Challenge can save a score in this browser only. It does not ask for an email, and it does not send what you type anywhere.

Two paths, one shared core

Shared core (Modules 1–4)

Everyone does these. Bug cards come in no-code versions (spreadsheet, flyer, web page) and a developer version (Java).

No-code path (Modules 5–7, N)

Test tables, a broken help-bot brief, and a shareable Proof Page. No coding.

Developer path (Modules 5–7, D)

The first track is Java & Spring Boot: a sample agent on a free mock model, a break-fix lab, and a Proof Kit repo with tests that run on every push.

Module 8

A free, self-scored skills check (Agent Proof Check) with Owner and Builder tracks. Not proctored, not accredited.

Modules

Available60–90 minShared core

1. Hands Off the Keyboard

Catch your “I’ll just fix it myself” reflex and swap it for a five-line brief.

  • You’ll learn: the three unlearnings; the five-line Brief Card (Intent, Context, Constraints, Done when, Examples); the Ownership Log; the Explain-It-Back test.
  • Activity: Hands-Off Challenge Level 1 (four bug cards), then see the tool (two bot briefs in the Agent Health Checker).
  • You leave with: My Playbook, page 1.

2. See the Tool: what an agent is made of

Open up a real agent, name its parts, and watch a free checker grade it.

  • You’ll learn: the parts of an agent (model, instructions, tools, loop, memory, guardrails, evals, plus observability and cost), what each can get wrong, and how to read a Health Checker scorecard.
  • No-code: read a help bot’s instructions, tools, and chat log like a manager.
  • Developer (Java/Spring): a primer mapping agent parts to Spring ideas, plus running the sample agent on a mock model.
  • You leave with: an anatomy sketch.

3. The Hands-Off Challenge: delegate a real fix

A game against your own habits: three levels, zero lines typed.

  • Activity: four decks (spreadsheet, document, web page, Java) and three levels. Level 3 has a bug the agent can’t fix without context only you have.
  • Bonus: the two-player “Human Agent” game, no AI needed.
  • You leave with: a Hands-Off scorecard and Ownership Log entries.

Module 3 promise

Coming soon60 min

4. Stay the Owner: never lose the plot

Let the agent type; you keep the whole picture and can prove it.

  • You’ll learn: before/during/after checkpoints, the Ownership Log, the Explain-It-Back test, and when to take the keyboard back.
  • Activity: “Spot the sneaky change,” where the agent fixed the bug and quietly changed something else.
  • You leave with: a “what changed and why” note.
